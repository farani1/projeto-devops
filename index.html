Projeto DevOps

Aplicação desenvolvida durante a disciplina de DevOps.

Este projeto tem como objetivo praticar conceitos de versionamento de código utilizando Git e GitHub.

Tecnologias utilizadas

  • HTML5
  • CSS3
  • Git
  • GitHub

Objetivos do projeto

  • Praticar o uso do Git para controle de versão.
  • Trabalhar com branches durante o desenvolvimento.
  • Registrar alterações por meio de commits.
  • Utilizar o GitHub para hospedagem do repositório.

Projeto acadêmico desenvolvido para a disciplina de DevOps.
